# Runbooks

<a href="#english">English</a> · <a href="#korean">한국어</a>

<a id="english"></a>
## English

- [Local operations](local-operations.md): start, diagnose, update, back up and
  optimize an existing installation.
- [Operations guide](../operations.md): detailed configuration, authenticated
  EC2 proxy/systemd setup, permissions and troubleshooting.
- [Onboarding](../onboarding.md): source installation, including macOS.

Commands in a runbook describe an operator action; maintaining documentation
does not execute those commands against a live installation.

<a id="korean"></a>
## 한국어

- [로컬 운영](local-operations.md): 기존 설치의 시작·진단·업데이트·백업·최적화.
- [운영 가이드](../operations.md): 상세 설정, EC2 인증 프록시·systemd 구성,
  권한과 문제 해결.
- [온보딩](../onboarding.md): macOS를 포함한 소스 설치.

런북 명령은 운영자가 수행할 절차입니다. 문서를 정리하는 작업이 해당 명령을
운영 설치에 실행하는 것은 아닙니다.
