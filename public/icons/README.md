# Assistant brand icons

These are original vendor assets used to identify the supported assistants.
The image files are preserved byte for byte; their artwork, colors and aspect
ratios have not been edited. Retrieved and inspected on 2026-09-25.

## Display and ownership

`ProviderMark` displays the files in a decorative, non-focusable SVG image
viewport. This retains the existing responsive icon sizes and the adjacent
assistant name supplies the accessible label. The `icons/...` references are
relative to the application's trusted document base, including proxy mounts.
No remote brand assets are fetched while using my-agent-ops.
